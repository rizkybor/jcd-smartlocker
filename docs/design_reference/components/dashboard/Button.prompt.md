Dashboard-scale button (32/40/48px). Use `KioskButton` instead for anything on the physical unit.

```jsx
<Button tone="primary">Simpan Perubahan</Button>
<Button tone="outline" size="sm">Ekspor CSV</Button>
<Button tone="danger" size="sm">Set Maintenance</Button>
```

Hover darkens the fill; press scales to 0.98. Only `ghost` has no elevation.
