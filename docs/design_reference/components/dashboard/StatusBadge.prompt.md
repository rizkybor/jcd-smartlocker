The single source of truth for status wording and colour in the dashboard — do not hand-roll pills.

```jsx
<StatusBadge status="online" pulse />
<StatusBadge status="occupied" />
<StatusBadge status="maintenance" size="lg" />
```

Labels default to Indonesian (Online / Tersedia / Terisi / Maintenance / Offline / Nonaktif). Green=free, yellow=in use, red=fault, grey=disabled — never remap these.
